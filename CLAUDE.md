## Critical: this is not the Next.js you were trained on

This repo runs **Next.js 16.4.2**, which has breaking changes vs. training data. Before writing or editing any Next.js-related code (routing, caching, data fetching, config), read the relevant page under `node_modules/next/dist/docs/` first. In particular:

- `node_modules/next/dist/docs/01-app/03-api-reference/05-config/01-next-config-js/cacheComponents.md`
- `node_modules/next/dist/docs/01-app/02-guides/adopting-partial-prefetching.md`
- `node_modules/next/dist/docs/01-app/02-guides/migrating-to-cache-components.md`

`next.config.ts` has `cacheComponents: true` and `partialPrefetching: true` enabled. This means:
- Data fetching is dynamic by default; opt in to caching per-function with the `'use cache'` directive (not `getStaticProps`/route segment `revalidate` patterns from older Next.js).
- `<Link>` prefetches a shared "App Shell" per route rather than per-URL content. Reading `params`/`searchParams` outside `<Suspense>` ties the shell to one URL — avoid that in new pages.
- The `experimental.ppr` flag and `runtime` route segment config are gone; don't add them.

Note: the currently existing pages (`src/app/**/page.tsx`) are all `'use client'` components that fetch via `useEffect` + the `services/*` layer — they don't yet use Server Components or `'use cache'`. Don't assume the existing pages demonstrate the intended Cache Components pattern; check the docs above when adding new data-fetching code.

The "NOT the Next.js you know" banner at the top of `AGENTS.md` is regenerated by `next dev` on every run (see `node_modules/next/dist/server/lib/generate-agent-files.js`) — leave it in place.

## Architecture

This is a frontend for a separate **Go backend API** (base URL from `NEXT_PUBLIC_API_URL` in `.env.local`). There is no backend code in this repo.

- `src/lib/apiClient.ts` — single shared axios instance. Request interceptors attach the bearer token read from the `token` cookie, then again from `localStorage` (client-only) if present — the second interceptor can override the first. A response interceptor logs (but does not yet redirect on) 401s.
- `src/services/*.ts` — one module per backend resource (`authService`, `storeService`, `appointmentService`), each exporting plain async functions that call `apiClient` and typed request/response interfaces matching the Go structs. New backend resources should follow this same thin-wrapper pattern rather than calling axios directly from components.
- `src/middleware.ts` — route-level auth gate. Reads the `token` cookie (not localStorage, since middleware runs on the edge/server) to redirect unauthenticated users away from private routes and authenticated users away from `/sign-in`/`/sign-up`. Update `publicRoutes` here when adding new unauthenticated pages.
- `src/app/**` — App Router pages. All current pages are client components (`'use client'`) that fetch data in `useEffect` rather than using Server Components.
- Auth token is persisted twice (cookie via `js-cookie`, 7-day expiry, and `localStorage`) — keep both in sync when touching `authService`.
- Path alias: `@/*` → `src/*` (see `tsconfig.json`).
- Styling is Tailwind CSS v4 via the Turbopack loader configured in `next.config.ts` (no `tailwind.config.*` file — v4 is CSS-config based, see `src/app/globals.css`).
