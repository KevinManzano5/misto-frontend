# Reglas de desarrollo — Misto Frontend

Este directorio contiene las reglas y estándares de desarrollo frontend/Next.js para este proyecto. Son vinculantes para cualquier código nuevo o modificado en este repositorio.

- [`nextjs.md`](./nextjs.md) — Reglas específicas de Next.js 16 (App Router, Cache Components, Partial Prefetching, data fetching, routing).
- [`react-typescript.md`](./react-typescript.md) — Estándares de componentes React, hooks y TypeScript.
- [`frontend-general.md`](./frontend-general.md) — Buenas prácticas generales de frontend (UI, accesibilidad, estilos, manejo de errores, estado).
- [`project-structure.md`](./project-structure.md) — Convenciones propias de este repo (capa de servicios, cliente HTTP, autenticación, idioma).

Antes de escribir código de Next.js, lee primero `node_modules/next/dist/docs/` (ver `AGENTS.md` en la raíz) — esta versión tiene cambios que rompen compatibilidad con el conocimiento previo del modelo. Estas reglas complementan, no sustituyen, esa documentación.
